Connect Google Drive

One-time setup, done by you in Google Cloud Console (free) — I can't create this for you, it needs your own Google sign-in:

  1. Go to console.cloud.google.com/apis/credentials
  2. Enable the "Google Drive API" for your project (APIs & Services → Library)
  3. Configure the OAuth consent screen (External, add yourself as a test user)
  4. Create Credentials → OAuth client ID → type "Web application"
  5. Under "Authorized JavaScript origins" add your Workpad URL, e.g. https://workpad-ai.vercel.app
  6. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it below
